# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately via email or GitHub Security Advisories.
Do not open public issues for security concerns.

## Security Practices

- Secrets are managed via GitHub Actions secrets and environment variables
- No credentials should be committed to the repository
- Enable GitHub secret scanning alerts
- Regular security audits are performed

## Supported Versions

Current main branch is actively maintained and monitored.
